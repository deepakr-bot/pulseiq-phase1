# PulseIQ: Data Analytics Project

One project in four phases. Each phase is a folder with its own README and code.

* **phase-1:** Data foundations (tasks 1 to 5)
* **phase-2:** People and teams (tasks 6 to 10)
* **phase-3:** Money and insight (tasks 11 to 15). Start with `phase-3/README.md`.
* **phase-4:** Release (tasks 16 to 20)

Phases build on each other. Phase 2 uses the data and warehouse from phase 1, and phase 3 uses the warehouse and metrics from phases 1 and 2.

Each phase's README explains how to install the packages and run its dashboards.

## Live links

* Dashboard (13 pages): https://pulseiq-dashboard.onrender.com
* Metrics API docs: https://pulseiq-metrics-api-mhmr.onrender.com/docs
* Release v1.0.0: https://github.com/deepakr-bot/pulseiq-phase1/releases/tag/v1.0.0

Both live services run on Render's free plan and sleep when idle. The first visit can take up to 60 seconds.
